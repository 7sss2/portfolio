# Akezhan — Портфолио

Личный сайт-портфолио: веб-разработка и AI-решения для бизнеса — сайты и лендинги, локальные сетевые сервисы, автоматизация на базе AI.

🔗 Разделы сайта: обо мне, навыки, проекты, контакты.

## Стек

- HTML5, CSS3, JavaScript (без фреймворков и сборщиков)
- Адаптивная вёрстка, плавный скролл, мобильное меню

## Структура

```
index.html    — разметка страницы
style.css     — стили и адаптив
script.js     — интерактивность (меню, плавный скролл, кнопка "наверх")
avatar.png    — фото профиля
favicon.svg   — favicon
```

## Запуск локально

Просто открыть `index.html` в браузере — сборка и зависимости не требуются.
